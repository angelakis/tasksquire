# Taskwarrior Android

An Android client for [Taskwarrior](https://taskwarrior.org/) that can sync with [TaskChampion Sync-Server](https://github.com/GothenburgBitFactory/taskchampion-sync-server).

> **Warning**: This project is vibecoded. Expect bugs, rough edges, and potential security issues. Use at your own risk.

## Features

- Task management with priorities, projects, tags, due dates, and dependencies
- TaskChampion sync protocol (Taskwarrior 3.x compatible)

## Building

```bash
# Debug
./gradlew assembleDebug

# Release (minified)
./gradlew assembleRelease
```

## Requirements

- Android 8.0+ (API 26)
